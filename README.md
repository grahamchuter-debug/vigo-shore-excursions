# World 2.0 Starter Template

Config-driven shore excursion site scaffold (Next.js + **Cloudflare Workers Static Assets** + Payments Worker).

New destinations deploy with `npm run deploy` (`wrangler deploy`) per ADR-0001.
Do **not** create Cloudflare Pages projects for new sites.

- **Architecture & inventory:** [STARTER_TEMPLATE.md](./STARTER_TEMPLATE.md)
- **Clone runbook (≤2h):** [CLONE.md](./CLONE.md)
- **Clone script:** `../scripts/clone-destination.mjs`

Do not ship this folder as a live destination. Clone it, then fill destination content only.
